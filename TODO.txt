## iXML Draft 2025-09-01 Changes (Beyond 1.0 + Errata)

This draft incorporates all 1.0 errata plus the following new features:

### Renaming/Aliasing Syntax (4 test cases affected)
- [x] Implement renaming/aliasing with `>` operator #HIGH
  - Status: COMPLETED (2026-06-04) - all four `correct/naming-*` tests pass
  - Grammar changes:
    - `naming: (mark, s)?, name, s, (-">", s, alias, s)?.` (NEW production)
    - `alias: name.` (NEW production)
    - `rule: naming, -["=:"], s, -alts, -".".` (was: `(mark, s)?, name, s, ...`)
    - `nonterminal: naming.` (was: `(mark, s)?, name, s.`)
  - Syntax: `B>X = "b".` means "match B but serialize as <X>"
  - Syntax: `S = A, B>C.` means "reference B but serialize as <C>"
  - Implementation:
    - Added aliases to grammar definitions and nonterminal references
    - Updated bootstrap grammar with naming/alias productions
    - Modified output generation to use aliases while preserving original parse targets
  - Files: src/ixml_bootstrap.rs, src/grammar.rs, src/parser.rs
  - Test impact: Fixed naming-elements, naming-elements-rhs, naming-attributes, naming-attributes-rhs

### Grammar Structure Refinements

  - Change: `ixml: s, (prolog, RS)?, rule++RS, s.` (was: `prolog?`)
  - Change: `prolog: version.` (was: `version, s.`)
  - Impact: Requires RS (required spacing) after prolog if present
  - Files: src/ixml_bootstrap.rs

  - Files: src/ixml_bootstrap.rs, src/grammar.rs (implement Cc Unicode category)
